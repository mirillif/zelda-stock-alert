Créer le jeton (une seule fois, 2 min)
  1. Ouvre github.com › Fine-grained token
  2. Nom : Zelda Monitor, expiration : 1 an
  3. Repository access : Only select repositories ›
  4. Permissions › Repository : Actions, Contents et Secrets en « Read and write »
  5. Generate token, puis colle-le ci-dessous
